# Pages overview

A Pages Project contains immutable Deployments and mutable Tags. Routes point to Tags, which makes promotion and rollback explicit. `latest` is system-managed; custom Tags can represent environments or release channels.

Artifacts are stored centrally and materialized on assigned nginx nodes. Optional wildcard previews use immutable deployment hostnames. Runtime configuration is public and separate from artifact identity.

Pages participates in scopes, folders, audit, notifications, retention, AI Workspace, MCP, and resource search. Disabling Pages removes it from normal navigation while preserving project data.
