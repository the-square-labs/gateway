# Product tour

Gateway organizes infrastructure around outcomes rather than individual servers.

<!-- screenshot: id=product-tour-navigation; viewport=1440x900; description=Expanded primary navigation with the major product areas visible; redact=instance-name,user-email -->

## Dashboard

The Dashboard summarizes health, recent activity, resource counts, active alerts, pinned resources, and system-level warnings such as an unavailable Relay or expiring license. Use it as the first operational checkpoint, not as a replacement for resource-specific diagnostics.

## Ingress

The Ingress workspace separates **Domains**, **Routes**, and **SSL Certificates**. A Domain chooses placement on an eligible nginx node. A Route defines traffic behavior and upstream ownership. A certificate remains centrally managed and is distributed only where an enabled TLS Route needs it.

## Docker

Docker provides standalone containers, blue/green Deployments, Compose Projects, images, volumes, networks, registries, builds, and durable Tasks. Gateway hides project-owned Compose children from standalone lifecycle controls to preserve project ownership.

## Databases

Store external PostgreSQL, Redis, or ClickHouse connections, or provision managed instances on database nodes. Managed databases are private by default. Applications connect through per-binding identities rather than receiving the database owner credential.

## Pages

Pages hosts immutable static-site deployments on nginx nodes. Tags provide mutable release pointers; Routes connect public domains to selected Tags. Business and Enterprise can build from connected Git repositories through isolated Build Workers.

## Observe

Monitoring, logs, notifications, status pages, structured logging, audit history, and optional SIEM delivery form one operational chain. Configure alerts around customer impact and state transitions instead of noisy implementation events.

## Access and administration

Settings, users, groups, scopes, authentication methods, API tokens, OAuth clients, integrations, licensing, and system operations are centrally administered. Resource-scoped permissions can grant access to a single Route, workload, database, or node rather than an entire product area.

## AI and programmatic operation

AI Workspace can discover documentation, plan work, and execute scoped Gateway operations. REST, OAuth, and MCP expose the same authorization and product contracts. Gateway Inference is a separate data plane with dedicated `gwi_` tokens, providers, accounting, and model access rules.
