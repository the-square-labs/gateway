# DNS, email, and webhooks

Cloudflare integration can manage supported Domain records and DNS-01 challenges. Use a narrowly scoped API token and verify the intended account and zone before enabling reconciliation.

Email configuration supports authentication flows and notification delivery where enabled. Test sender identity, TLS, deliverability, and rate limits before relying on email one-time codes.

Webhooks can trigger supported deployment or automation workflows. Use generated secrets, verify signatures, make receivers idempotent, and distinguish an accepted operation from a completed deployment. Do not return internal daemon errors or credentials in webhook responses.
