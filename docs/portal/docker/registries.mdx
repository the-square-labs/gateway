# Registries and image trust

Store private registry credentials in Gateway and scope their use to intended build or runtime paths. Configure a separate trusted token-service origin only when the registry intentionally delegates Bearer authentication there.

Gateway's internal Distribution registry stores approved build artifacts by immutable digest and retains active, rollback, in-progress, pinned, and recent successful artifacts. It does not require a public domain for internal use.

Optional external Docker-client access is a separate entitlement and ingress configuration. It requires selected nginx placement, Domain, TLS certificate, and repository/action-scoped token. Every token request rechecks current authorization and entitlement.

Never place registry passwords in image references, repository URLs, build logs, or screenshots.
